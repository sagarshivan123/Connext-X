Connect-X — Real-Time Chat Application

Connect-X is a full-stack real-time chat application built with the MERN Stack that enables users to communicate instantly with a secure authentication system and a modern responsive UI.
The application demonstrates real-world software engineering practices including authentication, protected routes, REST APIs, and scalable architecture.

## 🧰 Built With

**Frontend**
- React.js
- React Router
- Tailwind CSS
- Axios

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Authentication**
- JWT (JSON Web Token)
